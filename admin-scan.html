📷 Scan Recipe Photos & PDFs (AI, free & local)

Reads photos or PDFs using Ollama running on this same computer — nothing is uploaded anywhere. Pick as many files as you want. One-time setup: install Ollama, run ollama pull llama3.2-vision, then start it with OLLAMA_ORIGINS=* ollama serve so it accepts requests from this page.

⚠️ Important: this only works while you're viewing this page over plain http://, not the secure live site — browsers permanently block a secure page from calling Ollama, with no setting to allow it. Run node local-tools/scan-recipe/serve-locally.mjs in the project folder and open the http://localhost:8080 link it prints, then come back to this same page there.

📱 Scanning from your phone instead of the computer running Ollama?

Enter your computer's address on your home WiFi instead of "localhost" (e.g. http://192.168.1.42:11434). On the computer, find it under Wi-Fi settings, and start Ollama with OLLAMA_HOST=0.0.0.0:11434 OLLAMA_ORIGINS=* ollama serve so it accepts connections from other devices. This still requires viewing this page over http:// (see the warning above) — see local-tools/scan-recipe/README.md for the full walkthrough.

🧠 Model not loading? Change which Ollama model is used

If scanning fails with something like unknown model architecture, your installed Ollama version can't run llama3.2-vision yet. Try a different vision model instead — e.g. run ollama pull llava in Terminal, then type llava below. See local-tools/scan-recipe/README.md for more options.
