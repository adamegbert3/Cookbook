Something isn’t working?

“command not found: ollama”: open Ollama from Applications and finish its setup. Close and reopen Terminal. If needed, use /Applications/Ollama.app/Contents/Resources/ollama pull gemma3:4b.

“command not found: node”: install Node.js LTS, then close and reopen Terminal.

“address already in use”: another helper may already be running. Try the local setup link below. To replace an old helper, press Control-C in its Terminal window, then start the new one.

Photo won’t open: on the Mac, open it in Preview → File → Export → JPEG, then scan the JPEG.

Scan is slow or runs out of memory: close memory-heavy apps and start with one photo. The first scan can take longer while the model loads. Split long PDFs.

Local sign-in says unauthorized domain: ask the site owner to allow localhost in Firebase Authentication. Your live-site login and local login are separate.
