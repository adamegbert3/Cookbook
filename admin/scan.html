📷 Scan Recipe Photos & PDFs (AI, free & local)

Read recipe photos and PDFs with a local vision model. Start Ollama, then run ollama pull gemma3:4b once.

From the project folder, run node local-tools/scan-recipe/serve-locally.mjs. Open the local sign-in page, sign in, and return to Scan Photos there. Keep the helper running. Photos go to Ollama on the helper computer.

Choose a vision model

Enter an installed vision model name. If it is missing, run ollama pull MODEL_NAME first. Embedding and text-only models cannot read photos.

Review the transcription against the original before uploading, especially quantities and any [unclear] text.
